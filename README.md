# Hazırlıq Anar v3

Bu versiyada əsas maliyyə terminləri və hesablanma məntiqi yeniləndi.

## Dəyişikliklər

- "Aylıq potensial" adı "Bir aylıq maksimum gəlir" olaraq dəyişdirildi.
- "Alınmalı ümumi məbləğ" qarışıq olduğu üçün "Bu ay alınacaq məbləğ" olaraq dəyişdirildi.
- "Bu ay alınacaq məbləğ" artıq köhnə borcları özündə cəmləmir.
- Köhnə borclar ayrıca göstərilir.
- "Keçmiş aylardan borc" adı "1 aydan artıq ödənməyən pul" olaraq dəyişdirildi.
- Qrup panelləri, şagirdlər, ödənişlər və hesabat hissəsində eyni adlandırma tətbiq edildi.

## Məntiq

- Bir aylıq maksimum gəlir: aktiv şagirdlərin aylıq ödənişlərinin cəmi.
- Bu ay alınacaq məbləğ: yalnız cari ay üçün alınmalı olan məbləğ.
- 1 aydan artıq ödənməyən pul: əvvəlki aylardan qalan gecikmiş məbləğ.
