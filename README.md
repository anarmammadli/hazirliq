# Hazırlıq Ödəniş Sistemi

Bu versiyada cədvəl hissəsi yenidən düzəldildi.

## Yeni dəyişikliklər

- Cədvəlin üstündə olan statistik kartlar çıxarıldı.
- Cədvəl bölməsi artıq **real dərs cədvəli** görnüşündədir.
- Günlər sütun, saatlar isə sətir kimi göstərilir.
- Qruplar saat blokları kimi cədvəldə görünür.
- Hər qrup üçün rəngli schedule blokları əlavə edildi.
- Dizayn daha səliqəli və daha "actual schedule" görnüşünə uyğunlaşdırıldı.
- Əvvəlki premium mavi rəng palitrası saxlanıldı.

## Mövcud məntiq saxlanılıb

- Şagird qeydiyyatdan keçən gün borclu sayılmır.
- İlk ödəniş qeydiyyatdan 1 ay sonra yaranır.
- Qismən ödəniş qalığı azaldır.
- Ödənişlər ümumi alınmalı məbləği və borcu avtomatik yeniləyir.

## Açmaq üçün

1. ZIP faylını extract edin.
2. `index.html` faylını açın.
